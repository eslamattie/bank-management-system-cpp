# Bank Management System

Das ist ein einfaches Bankprogramm mit C++.

Ich habe dieses Projekt gemacht, um C++, objektorientierte Programmierung, Klassen, Vererbung und Dateiverarbeitung zu üben.

## Was kann das Programm?

- Kunden hinzufügen, ändern, löschen und suchen
- Benutzer hinzufügen, ändern, löschen und suchen
- Geld einzahlen
- Geld abheben
- Geld von einem Kunden zu einem anderen Kunden überweisen
- Kontostände anzeigen
- Mit einem Benutzernamen und einem Passwort anmelden
- Verschiedene Rechte für Benutzer verwenden
- Rechte mit Bits in einer Zahl speichern
- Dafür das Binärsystem benutzen
- Daten in Textdateien speichern

## Technologien

- C++
- Objektorientierte Programmierung
- Klassen und Vererbung
- Dateiverarbeitung
- Visual Studio

## Dateien

Das Programm speichert die Daten in diesen Dateien:

- `Clients.txt` - Daten der Kunden
- `Users.txt` - Daten der Benutzer
- `LoginRegister.txt` - Anmeldungen
- `TransferLog.txt` - Überweisungen

## Wie startet man das Programm?

1. Das Projekt in Visual Studio öffnen.
2. Die Datei `BankSystembyOOP.slnx` öffnen.
3. Das Projekt starten.
4. Einen Testbenutzer aus `Users.txt` benutzen.
